Books with cover, ISBN, multiple authors, category, publisher, year and replacement price. Kanban, list and form views.

Barcoded Copies

Membership numbers, expiry dates, personal loan limits, one-click yearly renewal and a complete loan history per member.

Complete Loan Cycle

Borrow, renew, return or mark as lost - with built-in rules that stop loans for expired members or unavailable copies.

06 / LIBRARY

Automatic Overdues

A daily scheduled action flags late loans, posts a note in the chatter and refreshes fines automatically.

07 / LIBRARY

Fine Management

Configurable daily fine rate, lost-book charge at replacement price, one-click fine payment, unpaid-fine blocking.

08 / LIBRARY

Reporting

Graph and pivot analysis of loans by month, status, category, book or member. Export to Excel with a click.

09 / LIBRARY

Role-based Security

Librarian and Manager groups. Administrators are managers automatically. Full audit trail through chatter.

Workflow

How Library Management works

An end-to-end workflow for everyday circulation.

01

Add books and copies

Create a title with ISBN, authors, and category. Create physical copies with individual barcodes and availability status.

02

Register members

Link a member to a contact, specify the membership expiry date and set the permitted loan limit.

03

Issue a loan

Choose an eligible member and an available copy, then confirm. The module checks borrowing conditions.

04

Renew, return, and track fines

Manage renewals, record returns and check charges related to overdue or lost copies.

Business rules and technical details

Business rules

✓  Expired memberships cannot borrow
✓  Per-member maximum simultaneous loans
✓  Members with unpaid fines are blocked
✓  Each physical copy can have only one active loan
✓  Renewals are limited and disallowed when overdue
✓  Only draft loans can be deleted; chatter maintains an audit trail
