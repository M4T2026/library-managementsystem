WORKFLOW

How it works, step by step

A straightforward circulation process from adding books to recording returns and fines.

01

Add books & copies

Create a book record with title, ISBN, authors and category. Add physical copies; each copy receives its own barcode and status.

02

Register a member

Link a contact, set membership expiry and a maximum number of simultaneous loans.

03

Issue a loan

Select a member and an available copy, then confirm. Eligibility, outstanding fines and availability are checked before a loan is issued.

04

Renew or return

Manage renewals within the applicable rules. On return, update the copy status and track overdue or lost-book charges where applicable.

CONTROL & SETUP

Practical rules. Straightforward setup.

Business rules

✓Expired memberships cannot borrow
✓Per-member maximum simultaneous loans
✓Members with unpaid fines are blocked
✓A copy can only be on one active loan
✓Renewals are limited and disabled when overdue
✓Only draft loans can be deleted; chatter maintains an audit trail
