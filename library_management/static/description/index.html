🚀 Overview

Everything your library needs — books, members, borrowings, reservations, fines, reports, and a stunning dashboard — all inside Odoo 19.

The Library Management System by mate4tech is a fully-featured, natively built Odoo 19 module. It covers every aspect of modern library operations — from cataloguing thousands of books with cover images and barcodes, to managing members with digital library cards, processing borrow & return workflows, tracking overdue items, calculating fines automatically, and sending email reminders — all backed by a real-time analytics dashboard.


✨ Key Features

12 core feature areas covering every aspect of library management.

📖

Complete Book Catalog

Title, ISBN/ISBN-13, barcode, cover image, authors, publisher, category, edition, pages, copies per book, shelf location, and rack number.

👥

Member Management

Photo ID, 5 membership types (Standard/Premium/Student/Senior/Corporate), per-type borrow limits, expiry tracking, and PDF library card printing.

🔄

Borrow & Return Workflow

Full cycle: Draft → Borrowed → Overdue → Returned/Lost, with status bar, chatter log, and printable borrowing slip.

⏰

Overdue & Fine Tracking

Daily automated overdue detection, configurable fine-per-day, damage/lost book fines, payment and waiver tracking.

📊

Real-Time Dashboard

KPI cards, 6-month trend line chart, category donut chart, top-borrowed books, and clickable live stats.

📧

Email Notifications

Automated HTML emails for due-date reminders (1 day before), overdue notices, and new member welcome messages.

📋

PDF Reports

Borrowing Slip, Overdue Report with totals, and Member Library Card — all printable from within Odoo.

🔖

Book Reservations

Reserve unavailable books, confirm when a copy becomes free, convert reservation to borrowing in one click.

🗂️

Hierarchical Categories

Multi-level category tree (e.g. Fiction → Mystery → Crime), publisher directory, and colour-coded book tags.

🧙

Smart Wizards

Issue Book Wizard (with member validation & info panel), Return Book Wizard (condition + fine calc), Renewal Wizard.

🔒

Role-Based Security

Librarian (operational) and Library Manager (full admin) security groups with granular model-level access rights.

Calendar View

⚙️ Installation Guide

Up and running in under 5 minutes.

1

Download the Module

Purchase & download the ZIP from the Odoo App Store. Extract to your addons directory.

2

Restart Odoo Server

Restart the Odoo service so the module is discovered.

sudo systemctl restart odoo
3

Activate Developer Mode

Settings → General Settings → Developer Tools → Activate Developer Mode.

4

Install from Apps

Apps → Search "Library Management" → Install. The Library menu appears automatically.

5

Assign User Roles

Settings → Users → select a user → Library Management → choose Librarian or Library Manager.

❓ FAQ

Q: Does it work on Odoo Community Edition?
Yes — fully compatible with both Odoo 19 Community and Enterprise.
Q: Can I change the fine-per-day rate?
Yes — set it per borrowing in the Issue Book Wizard. The default is 1.0 in your company currency.
Q: Are automated emails mandatory?
No — emails only send if the member has an email address and Odoo's outgoing mail server is configured.
Q: Can I import books in bulk?
Yes — use Odoo's built-in Import feature (list view → Import → Upload CSV/Excel).
Q: Is multi-company supported?
Yes — each borrowing is tied to a company, supporting multi-company Odoo instances.
Q: Can I customise the member card or borrowing slip layout?
Yes — edit the QWeb templates at Settings → Technical → Reporting → QWeb Templates.
